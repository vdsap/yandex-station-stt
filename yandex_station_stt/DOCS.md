# Yandex Station STT (Midi) — Автономное распознавание речи

Аддон запускает встроенную оффлайн нейросетевую модель распознавания русской речи, извлеченную из умной колонки Яндекс Станция Миди.

## 🚀 Возможности
- **100% Offline**: Работает локально на вашем оборудовании, не требует интернета и подписок Яндекса.
- **Ультра-быстрый инференс**: RTF ~0.013x (~77x быстрее реального времени на обычном CPU).
- **Архитектура Conformer RNN-T**: Вес всей модели всего 17 МБ (квантование FlatBuffers/TFLite FP32).
- **Нативная интеграция Wyoming**: Автоматически обнаруживается голосовым ассистентом Home Assistant Assist.

## ⚙️ Настройка
После запуска аддона Home Assistant автоматически предложит настроить интеграцию **Wyoming Protocol**. 

1. Перейдите в **Настройки → Устройства и службы**.
2. В найденных устройствах подтвердите добавление **Yandex Station STT**.
3. Перейдите в **Голосовые ассистенты → Assist**.
4. В поле **Распознавание речи (STT)** выберите **Yandex Station STT**.
